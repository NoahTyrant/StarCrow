# ⚠️ Source Code Usage Guidelines

If you want to use my source code to create your own scripts please respect my work and follow these rules:

- **Reference Only:** You may use small portions of my source code for learning and reference.
- **No Full Copying:** Do not copy the entire source code, take all its features, and simply rename it as your own.
- **Permission Required for Full Source:** If you want to obtain or use the complete source code, you must ask for my permission first.
- **Respect Original Work:** If you create your own script, develop your own features instead of simply copying and rebranding mine.
Thank you for respecting my work and effort.
